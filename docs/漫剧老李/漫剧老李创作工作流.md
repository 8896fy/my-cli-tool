# 漫剧老李 · 漫剧创作工作流

> 一套从「一个点子」到「一条发布成片」的标准化创作流水线。覆盖选题、剧本、视觉资产、制作、声音、发布与复盘。目标：**每一部漫剧可复用、可追踪、可量产**。

## 一、工作流总览（十阶段）

| 阶段 | 产出物 | 验收标准 | 默认状态 |
| --- | --- | --- | --- |
| ① 立项选题 | 高概念一句话 + 平台与受众 | 钩子明确，3 秒能讲清 | todo |
| ② 剧本大纲 | 三幕结构 + 情绪节点表 | 起承转合完整，爽点/泪点可定位 | todo |
| ③ 分镜脚本 | 镜头表（景别/运镜/时长/动作/对白） | 每镜头可独立执行，无歧义 | todo |
| ④ 角色设定 | 角色三视图 + 大头贴 | 纯灰/纯白背景，正/侧/背统一 | todo |
| ⑤ 场景设定 | 场景四视图（2×2 网格） | 90° 视角差、无缝衔接、空间锚点 | todo |
| ⑥ 视觉定调 | 风格样板 + 色板 + 光影参考 | 全片风格统一，情绪基调锁定 | todo |
| ⑦ 画面制作 | 成片画面素材 | 电影写实感 / 工业级渲染 | todo |
| ⑧ 声音制作 | 配音、音乐、音效 | 无旁白，纯动作 + 对白驱动 | todo |
| ⑨ 剪辑合成 | 时间线 + 字幕压制 + 片头片尾 | 节奏流畅，画音同步 | todo |
| ⑩ 审校发布 | 质检单 + 发布 + 数据复盘 | 通过发布清单，完成复盘 | todo |

## 二、核心规范

### 视听语言
- **无旁白**：剧情靠动作、对白与镜头语言推进，不靠文字解释。
- 情绪用光影与运镜表达。

### 角色三视图
- 正面 / 侧面 / 背面三视角 + 大头贴。
- 纯灰或纯白背景，聚焦角色本体。
- 三视角的五官、发型、服饰严格一致。

### 场景四视图
- 2×2 网格，四视角间保持 90° 视角差。
- 场景边缘无缝衔接，作为「空间锚点」。

### 空间与光影
- 关键场景标注绝对方位（东西南北 / 上下）。
- 每场戏设定绝对光影方向与情绪基调（暖 / 冷 / 明 / 暗）。

### 渲染标准（参考）
- 电影写实感、UE5 / Octane / 次世代 PBR、光线追踪。

## 三、进度追踪

在 `progress.json` 中为每个项目维护十阶段状态，取值：

- `todo` 未开始
- `doing` 进行中
- `done` 已完成
- `blocked` 被阻塞（在 `blocked` 字段写明原因）

仓库内置自动化 `manju-workflow-tracker`：
- 每周一 09:00 自动运行，也可手动触发。
- 读取 `progress.json`，计算每个项目完成度，汇总阻塞项，输出到 Actions 的 **Summary**。

## 四、发布质检清单（发布前逐项勾选）

- [ ] 无穿帮、无错别字、无乱码字幕
- [ ] 画音同步，节奏无拖沓
- [ ] 首帧钩子 ≤ 3 秒
- [ ] 无旁白（仅动作 + 对白）
- [ ] 封面 / 标题 / 简介符合平台规范
- [ ] 数据指标已约定（完播率、点赞、转粉）
